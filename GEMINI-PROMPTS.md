This is what appears when the link is shared on X, LinkedIn, etc. Make it count.

━━━━━━━━━━━━━━━━━ 100%
📝 Posted to X + LinkedIn ✓

Above the terminal: Bold white text "Post Shit Now" in a clean sans-serif font.
Below the terminal: Smaller text "CLI-First Social Media Growth System" in muted gray.

Electric green (#00FF88) glow emanating from the terminal screen, casting subtle light on the surrounding dark space. Small platform icons (X, LinkedIn, Instagram, TikTok) floating around the terminal as tiny holographic badges.

Style: Clean, minimal, dark mode aesthetic. NOT busy. Lots of negative space. The terminal is the hero. Professional but edgy.

## 2. Hero Background / Accent Image
For the hero section background or as a decorative element.

```
Abstract dark background image for a tech landing page. Pure black (#0A0A0B) base.

Subtle elements:
- A perspective grid receding into the distance at the bottom, lines in very dark green (#00FF88 at 5% opacity)
- Scattered floating particles/dots in electric green, very sparse
- A soft radial gradient glow in the center — green (#00FF88) fading to black, barely visible
- Faint horizontal scan lines across the entire image (CRT monitor effect, very subtle)

The overall effect should feel like looking into a terminal screen from far away. Minimal. Dark. Technical. NOT busy — this goes behind text so it must be subtle.

Resolution: 1920x1080, dark mode, no text.
```

## Usage Notes

- **OG Image (#1):** This is mandatory. It's what drives clicks from social shares.
- **Hero Background (#2):** Use as a subtle CSS background or decorative layer.
- **Icons (#3):** Optional — can use Lucide/Phosphor icons with CSS glow instead.
- **Terminal (#4):** Optional if Lovable builds a good CSS terminal mockup.
- **Platform Logos (#5):** Optional — can be done in CSS.
- **Before/After (#6):** This is for social media content ABOUT the landing page, not for the page itself. Generate this for your launch posts.
